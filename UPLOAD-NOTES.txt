WHAT TO UPLOAD
==============

Put all of these in your workout app repo, replacing the existing index.html:

  index.html          <- your file, PWA tags already added
  manifest.json
  sw.js
  icons/icon-180.png
  icons/icon-192.png
  icons/icon-512.png
  icons/icon-maskable-512.png

Nothing else to edit. The index.html changes are already applied.


INSTALLING ON IPHONE
--------------------
Open the site in SAFARI (not Chrome - iOS only allows installing from Safari).
Then: Share button -> Add to Home Screen.

You get the dumbbell icon on your home screen. Opening it launches full
screen with no address bar, and it works with no signal.


WHEN YOU UPLOAD A NEW VERSION LATER
-----------------------------------
Open sw.js and bump the version on the first line:

    const CACHE = "sicg-v1";   ->   const CACHE = "sicg-v2";

The app checks the network before the cache so updates normally arrive
anyway, but bumping the number guarantees it.
